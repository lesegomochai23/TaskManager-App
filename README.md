# Full-Stack Task Manager

A full-stack task management web application built with C# (.NET 10) and vanilla JavaScript.

## Features
- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Responsive dark-mode UI with cyan accents

## Tech Stack
- **Backend:** C#, ASP.NET Core Web API
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **API:** RESTful endpoints (GET, POST, PUT, DELETE)

## How to run locally
1. Clone the repository
2. Run `dotnet run` in the terminal
3. Open `http://localhost:5284` in your browser
